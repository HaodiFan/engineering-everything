# UI/UX 评判规则精简索引

与 `ui-ux-rules.md` 使用同一编号。每条一行：ID、标题、触发要点。完整字段（边界、证据、严重度、修复、复验）以规则正文为准。结论只许：通过 / 不通过 / 不适用 / 未验证。不打综合分。

共 69 条。

## 审计纪律
- `UX-META-01` 范围或主任务未定义就下结论 — 未说明审查哪一页、哪条任务、哪种材料，却给出「整体不好/已经很好」的判断。
- `UX-META-02` 把未观察到的行为写成已验证 — 静态截图或未实测的能力，被写成「焦点正确」「返回会保留筛选」「性能合格」「读屏可用」「主路径已跑通」。
- `UX-META-03` 编造综合分或未经证实的效果 — 出现总分、审美分，或承诺「这样会提升转化/完成率」，但没有对应实验或数据。
- `UX-META-04` 用偏好或参考站风格代替当前任务证据 — 以「不够高级」「不像某获奖站」为由要求改版，而未说明对当前任务的妨碍。
- `UX-META-05` 超出授权实施 — 用户只要求评判，却改代码、发消息或提交；或改动超出授权页面与共用组件。

## 任务与流程
- `UX-FLOW-01` 没有可检查的成功条件 — 只能描述「点了按钮」，不能说明系统怎样才算完成，或界面成功不等于真实完成。
- `UX-FLOW-02` 用错页面类型的检查重点 — 用营销首屏手法要求工具台大留白全屏动效，或把资料库页面当成转化落地页来评。
- `UX-FLOW-03` 为减少步骤去掉必要审阅或确认 — 以「少一次点击」为由，去掉费用核对、明确同意或高风险确认。

## 导航与位置
- `UX-IA-01` 无法识别当前位置与下一步 — 看不出自己在哪、当前对象是什么、下一步做什么。
- `UX-IA-02` 应可恢复的视图状态在返回或刷新后丢失 — 筛选、排序、分页、展开等可分享或应可恢复的状态，在刷新、复制链接或浏览器前进/后退后丢失；或把敏感信息写入 URL。
- `UX-IA-03` 从列表进入详情再返回后找不到原对象 — 返回后筛选、页码、选择或滚动位置被重置，用户须重找对象。
- `UX-IA-04` 链接与按钮语义用错 — 页面跳转做成无法新标签打开的假按钮；提交或危险动作做成看起来像普通链接且无预警。
- `UX-IA-05` 离开拦截不当 — 有未保存且会丢失的输入却不提醒；或没有修改也被反复拦截。

## 视觉层级与布局
- `UX-VIS-01` 不看图无法理解本页价值或任务 — 标题只有口号，去掉图片或装饰后说不出本页做什么、给谁、下一步是什么。
- `UX-VIS-02` 扫视无法区分主次 — 每个区块的字号、对比和位置都像主内容。
- `UX-VIS-03` 同一决策区内行动互相竞争 — 同一决策步骤里多个行动视觉权重接近、含义相近，无法判断当前该点哪个。
- `UX-VIS-04` 决策所需代价或限制远离操作点 — 价格、费用、库存、权限、不可逆后果等放在折叠区、另页或远离行动按钮的位置。
- `UX-VIS-05` 分组与对齐不能表达关系 — 相关标签、数值和操作对不上；或组内间距与组间间距几乎相同。
- `UX-VIS-06` 比较型数据用不适合比较的容器 — 需要横向比较同一组属性的数据被拆成难以对齐的大卡片；或本应独立进入的异质对象被硬塞进不适合的表。
- `UX-VIS-07` 密度与任务频率或错误成本不匹配 — 高频工作台被过大留白和重复容器拉开，或高风险核对区被拆散；相反，复杂首次说明被压成难读的密块。
- `UX-VIS-08` 视觉顺序与阅读或键盘顺序冲突 — 视觉上先看到的操作，在 DOM 或 Tab 顺序中很晚才出现，或窄屏重排后逻辑乱序。

## 排版与文案
- `UX-TYPE-01` 正文难以持续阅读 — 正文字号过小、行距过紧或过松、行长过宽或过窄，阅读吃力。
- `UX-TYPE-02` 中文或混排套用不当的拉丁展示规则 — 中文标题照搬极紧行高、大额负字距或全大写规则；中西数字混排基线或字重明显失调。
- `UX-TYPE-03` 重要文本被静默截断或破坏性断行 — 名称、金额、限制、状态在界面上被裁切且无法触及全文；或对普通正文使用破坏英文单词的断行。
- `UX-TYPE-04` 标题层级与内容结构不符 — 因样式跳过标题层级，或把卡片里所有句子都做成标题；字段只用占位符当标签。
- `UX-TYPE-05` 操作文案不能预测结果 — 主按钮是泛化的「确定」「提交」「好的」，看不出对象和后果。
- `UX-TYPE-06` 错误或状态文案不可行动 — 只有「参数错误」「失败」；或把系统失败归咎于用户，且无下一步。

## 颜色与对比
- `UX-COLOR-01` 仅用颜色传递意义 — 状态、选中、对错或图例只靠颜色区分，去掉颜色后无法理解。
- `UX-COLOR-02` 对比不足 — 正文、标签、禁用原因、轴标签或按钮文字与最终合成背景对比不足。
- `UX-COLOR-03` 语义色与真实含义不符 — 危险色用于普通强调或促销；涨跌色无文字说明且忽略地区差异；错误、警告、成功混用。
- `UX-COLOR-04` 深色或多主题未按最终状态检查 — 深色模式只是反相；或仅看令牌表，未检查输入边框、叠层、图表、原生控件和悬停/焦点/错误态。
- `UX-COLOR-05` 图表配色误导比较 — 用彩虹暗示不存在的顺序，图例与图形不一致，或漂亮的比例/坐标歪曲数据。

## 表单、表格与组件
- `UX-FORM-01` 标签不可见或以占位符代替 — 字段没有始终可见的标签，或提交前才告知格式、字数和限制。
- `UX-FORM-02` 禁止粘贴或阻碍密码管理器与自动填充 — 禁止粘贴；一次性验证码只能单格手输且不能整串粘贴；阻碍自动填充或密码管理器。
- `UX-FORM-03` 校验时机或错误更新不当 — 尚未输入就满页报错；输入过程中反复打断；用户改对后仍要再提交一次才消失错误；多字段失败只有顶部一句「参数错误」。
- `UX-FORM-04` 默认值代替用户作出有代价选择 — 预选订阅、附加收费、更宽权限或隐私共享，且不易发现和更改。
- `UX-FORM-05` 控件预期与生效时机不符 — 开关样式暗示即时生效，实际要等「保存」；或相反，已保存却无反馈。
- `UX-FORM-06` 提交保护不足或把未知结果当失败重试 — 提交中仍可重复发出有副作用请求；或结果未知时显示失败并鼓励再次支付、发送或创建。
- `UX-FORM-07` 筛选、搜索、空态或选择范围不明确 — 无结果时清掉查询且无法恢复；空数据与请求失败同一句话；批量操作未说明是当前页还是全部筛选结果。
- `UX-FORM-08` 组件模式误用 — 整张卡片的点击区域吞掉内部按钮…

## 状态与数据真实性
- `UX-STATE-01` 界面状态与系统事实不一致 — 把未知、排队、部分完成或失败显示为成功；或把缺失值显示为真实的零。
- `UX-STATE-02` 空、无结果、失败、权限混用同一表达 — 「暂无数据」同时用于尚未创建、筛选无命中、接口失败和无权查看。
- `UX-STATE-03` 加载反馈不当 — 瞬时操作也闪骨架；不可测进度被编成线性百分比；局部请求却用全页遮罩；重试无限旋转没有出口。
- `UX-STATE-04` 过期或错误请求的数据被当成当前结果 — 快速改筛选后旧请求结果覆盖新条件；或过期价格、过期列表不加说明仍当当前数据。
- `UX-STATE-05` 数据完整性、新鲜度或演示性质未标明 — 部分加载却看不出哪些还在获取；演示、示例或伪造的客户评价/奖项/数量未标识，甚至伪装成真数据。
- `UX-STATE-06` 把生成过程或推测显示为完成事实 — AI 或长任务在输出流动中就显示「已完成」；无证据的推测带有确定权威样式；「取消」掩盖已发生的外部动作；「再试一次」暗中再次发送或支付。

## 风险、权限与恢复
- `UX-RISK-01` 高风险提交前关键事实不清 — 支付、法律承诺、权限变更或不可恢复提交前，看不清对象、金额与币种、费用、时间/时区、接收方、范围或重要限制。
- `UX-RISK-02` 不可恢复操作缺少与风险相称的保障 — 删除、付款、外发等高代价动作可被默认焦点或误触直接执行，且无确认、审阅或撤销。
- `UX-RISK-03` 退出或拒绝路径被隐藏或被羞辱性文案阻碍 — 取消、拒绝、退出、导出或关闭明显更难找到；或用羞辱性文案逼迫接受。
- `UX-RISK-04` 文案承诺系统并不存在的恢复能力 — 界面写「可随时撤销/已保存到云端/已同步」，但系统没有这些能力。
- `UX-RISK-05` 权限表达不当或把隐藏控件当作安全边界 — 用隐藏按钮代替授权；禁用没有解释；看似局部的开关实际改组织级设置；普通用户路径未验证却按管理员成功路径放行。

## 动效
- `UX-MOTION-01` 功能依赖动画或动画不可打断 — 必须等动画播放完才能继续；中途关闭或反向仍要播完上一段；碰撞换向后动画原点仍指向旧方向。
- `UX-MOTION-02` 未提供减弱动态下的等价反馈 — `prefers-reduced-motion` 下内容不出现、关闭不完成，或只去掉动画却丢失状态变化反馈。
- `UX-MOTION-03` 高频操作被动画拖慢或滥用 transition:all — 每次输入、批量选择或常用快捷操作都要等出场动画；或 `transition: all` 导致布局和状态被意外动画。

## 性能
- `UX-PERF-01` 布局不稳定或媒体空间未预留 — 图片、字体、加载切换造成明显位移，遮住操作或改变点击目标；固定英雄区把内容推出屏幕。
- `UX-PERF-02` 把未实测的性能写成合格 — 无测量条件就把页面写成「很快」「不卡」，或用一次实验室结果代替真实用户数据。

## 响应式
- `UX-RESP-01` 窄屏或中间宽度下必要操作不可用或被遮挡 — 必要操作被隐藏、重叠，或被粘性栏、安全区、键盘挡住。
- `UX-RESP-02` 唯一入口依赖悬停 — 关键操作、关键说明或关键数据只在 hover 时出现。
- `UX-RESP-03` 重排丢失必要数据或整页被撑开 — 为了「简洁」直接删除比较所需的列；或一个超宽子元素撑开整页，横向滚动不可发现。
- `UX-RESP-04` 禁止用户缩放或文字放大后被裁切 — 禁止浏览器缩放，或固定高度在放大、长翻译后裁切文字。

## 无障碍
- `UX-A11Y-01` 键盘无法完成核心任务或出现意外焦点陷阱 — Tab/方向键/Enter/Esc 无法完成主任务，或焦点进入后无法离开（模态内受控循环须有可用退出路径）。
- `UX-A11Y-02` 焦点不可见或被遮挡 — 焦点没有可见指示，或被粘性头尾、浮层完全挡住。
- `UX-A11Y-03` 控件缺少正确名称、角色或状态 — 图标按钮没有可访问名称；可见标签与无障碍名称相反；自定义控件缺少名称、角色或状态。
- `UX-A11Y-04` 对话框或浮层的焦点与关闭行为不符合模式 — 打开后焦点未进入对话框；背景仍可交互；Esc 无效；关闭后焦点丢失或跑到页顶；把关闭当成已提交。
- `UX-A11Y-05` 状态变化不能被辅助技术获知 — 搜索结果数量、保存成功、上传失败等不移动焦点的状态变化，辅助技术完全不知道；或把每个按键、每帧进度都做成打断性播报。
- `UX-A11Y-06` 图像与图标的替代文本不当 — 信息性图片没有替代文本；装饰图被重复朗读；复杂图表既无结论也无数据访问方式；视频未播放就无法理解首屏。

## 待执行的研究检查（未做不自动判不通过）
- `UX-RES-01` 目标用户与任务假设尚未验证 — 方案依赖特定用户动机或使用情境，但没有相应访谈、支持请求或使用数据。
- `UX-RES-02` 关键任务尚未做可用性观察 — 争论用户会不会迷路、会不会误点，但没有走查、可用性任务或行为数据。
- `UX-RES-03` 信息架构尚未用方法验证 — 导航分组或命名有争议，且未做卡片分类、树测试或等效验证。
